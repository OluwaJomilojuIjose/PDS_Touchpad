# PDS_Touchpad
A dedicated app for using the Ayaneo pocket-DS' button screen as a touchpad for stuff like windows and wii emulation while leaving the bottom screen switched on.
Will either require a rooted device to function or allocating the app to run with root access
Also has some additional features like changing the artwork on the app via steamgriddb scraping, will require the user inputting their steamgriddb api key for this feature to be used.
